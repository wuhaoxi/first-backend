Single Maven module (`pom.xml`) inheriting `spring-boot-starter-parent:3.3.6` and declaring the application artifact `com.first:my-first-project-backend`. Dependencies are organized as Spring Boot starters — `spring-boot-starter-web`, `spring-boot-starter-data-jpa`, `spring-boot-starter-validation` — plus runtime drivers (`mysql-connector-j`, `spring-boot-devtools`) and test-only `h2`/`spring-boot-starter-test`. Lombok is included as an optional annotation processor and excluded from the Spring Boot executable jar via the `spring-boot-maven-plugin` configuration. The build uses the default Surefire plugin (v3.2.5) and the project ships a Maven Wrapper (`mvnw`/`mvnw.cmd`). Profiles documented in README.md switch between MySQL (`dev`, default) and H2 (`test`).
